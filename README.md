# pairwise-waypoints

## 题面（可直接粘贴）

路径跟随。约束：按距离取点正确；必须实现按弧长等距重采样与切线计算，支持 Catmull-Rom 平滑且平滑后偏差不超过给定上界；10 万段等距采样不超过 300 ms；并发安全；重复点、零长度、负距离要给出可区分的错误。验收：python -m pytest tests -q -k waypoint。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 1 万段耗时
- 并发
- 非有限坐标
- 重复点
- 超长距离

## 运行方式

```bash
python -m pytest tests -q
```
